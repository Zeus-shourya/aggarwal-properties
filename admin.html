Website editor

Mark plots as sold or available yourself. No coding. The website updates on its own a minute or two after you save.

Open the editor → Try it on the map first

Mark a plot as sold

  1. Open the editor with the button above and log in with the email that was invited. ऊपर वाले बटन से Editor खोलें और invite वाले email से login करें।
  2. Open aggarwal-properties, then click Sold plots on the left. बाईं तरफ़ Sold plots पर क्लिक करें।
  3. Find the project (MANSA - 06, MANSA - 05 or MANSA - 04). Click its box, type the plot number and pick it from the list. Repeat for every sold plot. Project चुनें, box में plot number लिखें और list में से चुनें। हर बिके हुए plot के लिए ऐसा ही करें।
  4. Click Save. In about 1–2 minutes those plots turn red on the website. Every plot that is not in the list stays green. Save दबाएँ। 1–2 मिनट में वे plot वेबसाइट पर लाल (sold) दिखेंगे। बाकी सब हरे (available) रहेंगे।

Good to know

Plot available again?

Open Sold plots, click the small × next to that plot number to remove it from the list, then Save. It turns green again.

Not sure which plot?

Open the map with Try it on the map first. Clicking plots there only previews red and green; nothing is saved until you use the editor.

Two plots with one number

MANSA - 05 has two plots numbered 97 and MANSA - 04 has two each of C-5, C-6 and C-7. The list shows the size beside each one so you can pick the right plot.

Still showing the old colour?

Wait two minutes and refresh the page. On a phone, pull down to refresh.
